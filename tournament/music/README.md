# Saved music

Stored for later use. None of this is in the game.

- `trap_no_bell_no_slide_loop.mp3` / `.wav`: the trap beat Justin picked on 2026-11-20. No bell melody, bass does not slide. One seamless loop, about 14 seconds, 140 bpm.
- `trap_no_bell_loop.mp3`: the same beat with the bass slides left in.
- `beats.py`, `v2.py`: the scripts that generate them (numpy + scipy + ffmpeg). Everything is synthesized; no samples.

## Justin's recordings

- `chips/original_recording.m4a`: the chip recording as sent. `chips/A…H`: the eight clips cut from it. `A_single_clack` is the NEXT button on the tips.
- `can/original_recording.m4a`: the spray can shake as sent. The game uses 1.30s to 2.06s of it at the start of the intros.
- `can/shake_*.mp3`: experiments that built a can shake out of the chip clips. Not used.
